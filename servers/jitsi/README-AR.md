# تجهيز سيرفر الاجتماعات على Contabo وربطه بـ 7PRO

كل حاجة في التطبيق والباك إند جاهزة. السيرفر الحالي (المجتمعي) لسه هو النشط، فمفيش أي حاجة هتتغير للطلاب لحد ما تفعّل سيرفرك بنفسك.

## 1) قبل الشراء

- **المواصفات المقترحة كبداية:** 4 أنوية CPU، و8 جيجا رام، وUbuntu 22.04 أو 24.04. ارفع المواصفات لو الحصص كبيرة أو متزامنة.
- **مكان السيرفر:** اختار أقرب داتا سنتر لطلابك (أوروبا غالبًا الأقرب لمصر).
- **دومين فرعي:** هتحتاج دومين زي `meet.7pro.app` (أو أي دومين عندك).

## 2) بعد الشراء

1. من لوحة الدومين، اعمل **A record**: الاسم `meet` والقيمة هي IP سيرفر Contabo. استنى 5–10 دقايق.
2. ادخل على السيرفر:
   ```
   ssh root@IP_السيرفر
   ```
3. ارفع السكريبت وشغّله:
   ```
   scp servers/jitsi/install-jitsi.sh root@IP_السيرفر:/root/
   bash /root/install-jitsi.sh meet.7pro.app 7pro7777@gmail.com
   ```
4. في الآخر السكريبت هيطبعلك 3 حاجات: **الدومين**، و**JWT App ID**، و**JWT Secret**.

السكريبت بيعمل الآتي: يسطّب Docker، ويفتح البورتات (22 و80 و443 TCP، و10000 UDP)، وينزّل Jitsi الرسمي، ويطلّع شهادة HTTPS مجانية، ويقفل التسجيل وصفحة التحضير، ويشغّل حماية JWT.

## 3) في التطبيق

1. افتح **لوحة المالك ← النظام ← سيرفرات الاجتماعات**.
2. على كارت **سيرفر Contabo** دوس **تعديل**، واكتب الدومين والـ App ID والـ Secret، وبعدين **حفظ**.
3. دوس **اختبار**. لازم يطلعلك: «السيرفر رد وبيشغّل Jitsi تمام».
4. دوس **فعّله** ← تأكيد.

بعد التفعيل:
- كل الحصص الجديدة والمجدولة بتتنقل على Contabo.
- الحصص الشغالة دلوقتي بتكمل على السيرفر القديم لحد ما تخلص.

**الرجوع لسيرفر تاني:** دوس «فعّله» على السيرفر اللي عايزه (Hetzner أو المجتمعي)، وده بيحصل في ثانية.

## 4) الصلاحيات

- المالك عنده الشاشة دايمًا.
- عشان أدمن يشوفها، اديله صلاحية **«سيرفرات الاجتماعات (تبديل وتعديل)»** من صلاحيات الأدمن.
- الـ JWT Secret بيتحفظ في جدول محدش يقدر يقراه غير السيرفر نفسه. حتى المالك مش بيشوفه تاني بعد الحفظ، بيشوف بس «محفوظ».

## 5) خطوة لازم تتعمل مرة واحدة

صفحة الفصل في المتصفح (`web/classroom.html`) اتعدّلت عشان تبعت الـ JWT. لازم ترفعها تاني على Cloudflare (`7pro-x7.7pro7777.workers.dev`) زي ما بتعمل عادةً. التطبيق نفسه هيحتاج بيلد جديد من Rork عشان الشاشة الجديدة تظهر.

## 6) لو فيه مشكلة

| العَرَض | الحل |
|---|---|
| «اختبار» بيفشل | اتأكد إن الـ A record صح، وشغّل `cd /opt/7pro-jitsi && docker compose logs web` |
| الصوت والفيديو مش بيوصلوا | بورت 10000 UDP لازم يكون مفتوح، شغّل `ufw status` |
| الطالب واقف على «في انتظار المضيف» | طبيعي لو دخل قبل المعلم، أول ما المعلم يدخل الحصة بتفتح |
| عايز سيرفر مفتوح بدون JWT | `OPEN_SERVER=1 bash install-jitsi.sh ...` وسيب خانات الـ JWT فاضية في التطبيق |

نفس السكريبت والخطوات بالظبط بيشتغلوا على **Hetzner** لو حبيت تجهّزه هو كمان.
