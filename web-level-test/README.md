# 7PRO — اختبار تحديد المستوى (من غير تسجيل دخول)

نسخة الويب من شاشة «اختبار تحديد المستوى» في التطبيق. صفحة واحدة (`public/index.html`) من غير build.

## بتشتغل إزاي من غير دخول
الصفحة بتفتح **جلسة ضيف** تلقائيًا (Supabase anonymous sign-in، نفس اللي بيستخدمه الفصل الافتراضي).
الضيف بياخد ملف شخصي ACTIVE تلقائيًا، فنفس دوال التطبيق شغّالة من غير أي تعديل في القاعدة:
`placement_tests` ← `start_test_attempt` ← `next_test_question` ← `submit_test_answer` ← `finish_test_attempt`.
التصحيح وتحديد مستوى CEFR كله على السيرفر.

## اللي بيظهر
- نفس الشاشة اللي في التطبيق: «اكتشف مستواك بدقة» + مقياس C2…A1 + «الاختبارات المتاحة».
- الاختبارات هي اللي المالك نشرها (`kind = PLACEMENT`, `status = PUBLISHED`) بنفس ترتيبه (`sort_order`).
- القفل زي التطبيق: الاختبار اللي بعده بيتفتح لما الاختبار اللي قبله يتعدّى درجة نجاحه.
- قبل البداية بيطلب **الاسم** (والموبايل اختياري) علشان المالك يشوف صاحب النتيجة في «آخر نتائج تحديد المستوى». الاسم بيتحفظ على ملف الضيف.
- الأسئلة: اختيار واحد / أكتر من إجابة / صح وخطأ / كتابة. بتظهر صورة أو صوت أو فيديو السؤال لو موجودين. تايمر من السيرفر.
- النتيجة: المستوى (CEFR) والنسبة والمهارات ونقاط القوة والضعف، وزرار «احجز جروب مناسب لمستواك» بيفتح صفحة الحجز.

## النشر على Cloudflare
```
cd web-level-test
npx wrangler deploy
```
الرابط: `https://7pro-level-test.<subdomain-حسابك>.workers.dev/`

أو من Dashboard: Workers & Pages ← Create ← Upload assets ← ارفع فولدر `public` (اسم المشروع `7pro-level-test`).

مفيش Redirect URLs تضيفها (مفيش دخول بحساب خارجي) ومفيش migrations.

## إعدادات في الصفحة
في أول الـ script:
- `BOOKING_URL`: رابط صفحة الحجز (`https://7pro-pay.7pro7777.workers.dev/`). غيّره لو الرابط اتغيّر.

## ملاحظات
- الضيف مرتبط بالمتصفح: لو مسح بيانات المتصفح يبدأ ضيف جديد وبيتصفّر تقدّمه (القفل بيعتمد على نتايجه).
- لو الشخص داخل بحساب 7PRO في نفس المتصفح، نفس الجلسة بتتستخدم ونتيجته بتتسجّل على حسابه.
- أسئلة الترتيب والتوصيل (ORDERING/MATCHING) التطبيق نفسه مش بيعرضها، فالصفحة بتقدّم «تخطي السؤال» زيه.
