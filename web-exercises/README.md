# 7PRO — صفحة تمارين المعلم (للطلاب المشتركين معاه فقط) + الإعلانات

المعلم بينسخ الرابط من **استوديو المعلم ← تدريباتي** ويبعته لطلابه. الرابط بيفتح صفحة الويب دي.

## الروابط
| الرابط | بيفتح |
|---|---|
| `/?teacher=<teacher_id>` | كل تمارين المعلم (المنشورة) |
| `/?teacher=<teacher_id>&ex=<test_id>` | تمرين معيّن مباشرة |

## مين يقدر يفتحه (الحماية على السيرفر)
الصفحة بتطلب تسجيل دخول (Google أو إيميل، وفيها إنشاء حساب). بعد الدخول، الدالتين `web_teacher_exercises` و`web_start_exercise`
بترفضوا بـ `NOT_SUBSCRIBED` أي حساب مالوش اشتراك **معتمد (APPROVED) وغير متوقف** مع المعلم ده.
المعلم نفسه وفريق الإدارة بيفتحوا عادي. الحساب غير المشترك بيشوف رسالة وزرار «احجز جروب مع المعلم».

التصحيح بعد كده بنفس دوال التطبيق (`next_test_question` / `submit_test_answer` / `finish_test_attempt`)، ونتايج الطلاب بتظهر للمعلم زي ما هي.

## الإعلانات
من التطبيق: **لوحة المالك/الأدمن ← إعلانات الويب** (بتظهر لمن عنده صلاحية `ads.manage`).
4 أماكن: أعلى الصفحة، تحت كل سؤال، صفحة النتيجة، أسفل الصفحة. لكل مكان تختار نوع:
- **صورة + رابط**: رابط الصورة لازم يبقى https.
- **AdSense**: معرّف الناشر `ca-pub-…` ومعرّف الوحدة. AdSense بيشتغل بس على دومين معتمد عندك، وعنوان `workers.dev` غالبًا مش معتمد (محتاج دومين خاص).
- **كود HTML**: بيتعرض جوه iframe معزول (`sandbox` من غير `allow-same-origin`) فمايقدرش يوصل لجلسة الطالب.

مفتاح «عرض الإعلانات في صفحات الويب» بيخفي كل الإعلانات مرة واحدة.
**وحدات AdMob بتاعة التطبيق مش بتشتغل على الويب** — دي حاجة منفصلة.

## النشر على Cloudflare
```
cd web-exercises
npx wrangler deploy
```
الرابط: `https://7pro-exercises.<subdomain-حسابك>.workers.dev/`
أو من Dashboard: Workers & Pages ← Create ← Upload assets ← ارفع فولدر `public` باسم `7pro-exercises`.

لو الرابط طلع مختلف، غيّر ثابت واحد في التطبيق: `ExerciseWeb.BASE_URL` (ملف `data/ExerciseWeb.kt`).
