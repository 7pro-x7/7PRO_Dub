# 7PRO — صفحة الدفع (حجز جروب + تجديد الاشتراك)

نسخة الويب من شاشة «حجز جروب» في التطبيق. صفحة واحدة (`public/index.html`) من غير build.
بتكلم نفس Supabase ونفس الدوال اللي التطبيق بيستخدمها، ومفيش حاجة بتتفعّل من الصفحة:
الحجز والتجديد بيفضلوا طلبات لحد ما المالك/الأدمن يوافق عليهم (نفس مسار التطبيق).

## النشر على Cloudflare

**بالـ wrangler:**
```
cd web-pay
npx wrangler deploy
```
الرابط: `https://7pro-pay.<subdomain-حسابك>.workers.dev/` (لحسابك: `https://7pro-pay.7pro7777.workers.dev/`)

**من غير أوامر:** Cloudflare Dashboard → Workers & Pages → Create → Upload assets → ارفع فولدر `public` (اسم المشروع `7pro-pay`).

لو اسم الـ Worker أو الدومين مختلف، غيّر ثابت واحد بس في التطبيق: `PayWeb.BASE_URL` (ملف `data/PayWeb.kt`).

## الروابط

| الرابط | بيفتح |
|---|---|
| `/` | صفحة اختيار المعلم (زي الصورة) |
| `/?teacher=<teacher_id>` | جروبات معلم معيّن |
| `/?teacher=<teacher_id>&group=<group_id>` | حجز جروب معيّن مباشرة |
| `/?renew=<subscription_id>` | تجديد اشتراك طالب معيّن |

رابط التجديد بيتنسخ من التطبيق: أيقونة 🔗 جنب كل طالب (لوحة المالك / الأدمن / استوديو المعلم → الاشتراكات → الجروب، وكمان في «التجديدات القادمة»).

## لازم تعمله مرة واحدة (Supabase → Authentication → URL Configuration)

ضيف رابط الصفحة في **Redirect URLs** (علشان «الدخول بحساب Google» وإعادة تعيين كلمة السر يرجعوا للصفحة):
`https://7pro-pay.7pro7777.workers.dev/**`
الدخول والتسجيل بالإيميل وكلمة السر شغّالين من غير أي إعداد.

## الدخول والتسجيل

- زرار **الدخول بحساب Google** فوق، بضغطة واحدة (بيشتغل بعد إضافة الـ Redirect URL).
- تبويب **إنشاء حساب**: الاسم + الإيميل + كلمة السر (6 أو أكتر) + الموبايل اختياري. بيتسجّل بنفس طريقة التطبيق وبيدخل على طول من غير تأكيد إيميل.
- تبويب **تسجيل الدخول** فيه «نسيت كلمة السر».
- أول دخول بأي طريقة بيستدعي `ensure_my_profile` علشان الملف الشخصي يتعمل زي التطبيق.

## ملاحظات

- رابط التجديد بيشتغل **بحساب الطالب نفسه** فقط. لو حد تاني فتحه بيظهرله إن الرابط تابع لحساب تاني. الـ id لوحده مش بيدّي أي صلاحية.
- الطالب اللي متضاف من المعلم من غير ما يتربط بحسابه (student_user_id فاضي) الرابط مش هيشتغل له، والتطبيق بيقولك اربط الحساب الأول من «تعديل».
- التجديد بيفتح قبل الميعاد بعدد الأيام في الإعداد `subscription.renewal_window_days` (الافتراضي 3). قبل كده الصفحة بتقول للطالب ميعاد الاشتراك.
- صور الإثبات بتترفع في bucket `payment-proofs` الخاص، وبتتصغّر تلقائيًا لو كبيرة.
